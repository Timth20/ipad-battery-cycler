# iPad 全自动循环充放电：设置指引

这个仓库只有一个网页 `index.html`（「耗电机」）：页面在前台就把 GPU 和 CPU 压满，进后台就停。
它不读电量、不发任何网络请求、不含任何密钥，可以放心放在公开仓库里。

---

## 0. 方案一览

**插座当主时钟，iPad 只负责跟随。不需要 Voice Monkey。**

```
Alexa 定时例行程序（每天固定几个时刻）
   插座通电 ──► iPad 检测到「充电器已连接」──► 调暗 + 回主屏幕（网页停，专心充电）
   （等待 Wc）
   插座断电 ──► iPad 检测到「充电器已断开」──► 亮度 100% + 打开网页（满载放电）
   （直到下一个定时时刻，循环）

本地兜底：电量降到 10% 以下 ──► 调暗 + 回主屏幕（停止放电，等下一次通电）
```

和原方案（Voice Monkey 触发）相比，改了什么、为什么：

| 改动 | 理由 |
|---|---|
| 去掉 Voice Monkey，插座改为纯定时 | 少一个第三方服务、一个 token、一个每月额度，也不依赖「iPad 在 10% 时那一次请求必须成功」。定时例行程序互相独立，某一次没执行，下一次照常，循环自己就回到正轨 |
| 10% 的动作从「发请求」变成「本地停机」 | 不需要网络，最不容易失败。真正决定充电的是插座的时钟 |
| 放电窗口设成比「满载放到 10% 的时间」短 10 分钟 | 正常情况下根本碰不到 10%，10% / 5% 两条自动化只是保险 |
| 「打开 App Safari」改成「打开 URL」 | 不管 Safari 当时停在哪个页面、有没有被系统回收，都能保证耗电页在最前面。标签页堆积用「一天后自动关闭标签页」解决 |
| 自动化里的网址带 `?auto=1` | Safari 会清掉 7 天没人点过的网站的本地存储，只靠「点过一次开始」的记忆，无人值守一周后会失效。带参数就不依赖存储 |

代价：需要先花一轮时间实测两个数字（第 4 步），之后是固定节奏，不会随每一轮的实际情况自动伸缩。

## 1. 发布网页（GitHub Pages）

1. 登录 github.com → 右上角 **+** → **New repository**
2. Repository name 填 `ipad-battery-cycler`，选 **Public**，点 **Create repository**
3. 在新仓库页面点 **uploading an existing file**，把 `index.html`（和这份 `README.md`）拖进去 → **Commit changes**
4. 仓库 **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → Branch 选 **main**、文件夹 **/(root)** → **Save**
5. 等 1–2 分钟，Pages 页面顶部会显示网址：

   `https://Timth20.github.io/ipad-battery-cycler/`

之后会用到两个网址：

- 普通网址（上面那个）：打开**不会**自动跑，要点一次「开始」（点过之后这台设备才会记住）。在 iPad 上**不要点**，这样它就是一个只看记录、不耗电的入口
- **自动网址**：`https://Timth20.github.io/ipad-battery-cycler/?auto=1` —— 一打开就满载。只填在 iPad 的快捷指令里

## 2. iPad 设置

逐项改（「设置」App）：

| 位置 | 改成 |
|---|---|
| 显示与亮度 → 自动锁定 | **永不** |
| 辅助功能 → 显示与文字大小 → 自动亮度 | **关**（否则系统会把亮度调回去） |
| 电池 → 低电量模式 | **关** |
| 电池 → 电池健康 / 充电（有这一项的机型） | 关闭「80% 上限」，或把充电上限拉到 **100%** |
| 通用 → 软件更新 → 自动更新 | 全部**关**（避免半夜弹窗、自动重启） |
| App → Safari → 关闭标签页 | **一天后** |
| 专注模式 → 勿扰模式 | 建议**开**（避免来电全屏打断） |
| 隐私与安全性 → 分析与改进 → 共享 iPad 分析 | **开**（老机型查循环次数要用，见第 9 步） |

其他：

- 充电头用这台 iPad 支持的最大功率（多数机型 20W–30W 以上即可，再大也不会更快）
- **取下保护壳**，平放在硬质、不可燃的台面上（桌面、瓷砖），周围不要有纸张、布料
- 可选：关掉锁屏密码（设置 → 面容 ID / 触控 ID 与密码 → 关闭密码）。好处是没电关机再开机后少一步解锁；坏处是任何人拿起来都能用，自己权衡
- 电量 20% 和 10% 时系统会弹「电量不足」提示框，不影响网页运行，不用管

## 3. 建 4 条快捷指令自动化

「快捷指令」App → 底部 **自动化** → 右上角 **+**。
每一条都选 **立即运行**，并关掉 **运行时通知**。

### A. 充电器已连接 → 停止耗电

- 触发：**充电器** → 勾选 **已连接**
- 动作：
  1. **设定亮度** → 滑到 **0%**
  2. **前往主屏幕**

### B. 充电器已断开 → 开始耗电

- 触发：**充电器** → 勾选 **已断开连接**
- 动作：
  1. **获取电池电量**
  2. **如果** → 条件设为 `电池电量` **大于** `15`
  3. （放在「如果」里面）**设定亮度** → **100%**
  4. （放在「如果」里面）**打开 URL** → 填**自动网址**（带 `?auto=1` 的那个）
  5. **结束如果**（「否则」分支留空）

  「大于 15」的作用：万一某次充电没成功（插座没通电），断开时不会在低电量下继续硬跑到关机。

### C. 电量降到 10% 以下 → 停止耗电（兜底）

- 触发：**电池电量** → 拖到 **10%** → 选 **降至 10% 以下**
- 动作：
  1. **设定亮度** → **0%**
  2. **前往主屏幕**

### D. 电量降到 5% 以下 → 同 C（双保险）

- 触发：**电池电量** → **5%** → **降至 5% 以下**
- 动作同 C

## 4. 实测两个数字（校准，一次即可）

需要知道：

- **d** = 满载从 100% 掉到 10% 要多久
- **c** = 待机亮屏从 10% 充到 100% 要多久

做法（全程用 Alexa App 手动开关插座，快捷指令已经在工作）：

1. 手动打开插座，把 iPad 充到 100%
2. 手动关闭插座 → 自动化 B 触发，网页开始满载。**记下时间**
3. 不用守着。电量到 10% 时自动化 C 会让它停下来。回来后在 Safari 里打开**普通网址**（不会开始耗电），看「运行记录」里刚才那一段的**时长**，这就是 **d**
4. 手动打开插座，**记下时间**。两三个小时后看 设置 → 电池 里的电量曲线，找到升到 100% 的时刻，差值就是 **c**

然后算出三个值：

- **放电窗口 Wd = d − 10 分钟**（向下取整到 5 分钟）
- **周期 P**：从下表选**最小的**、满足 `P ≥ Wd + c` 的一档。只差 10–15 分钟也可以选小的那档（充到 95% 左右就断电，最后那段涓流本来就慢）
- **充电时长 Wc = P − Wd**

| 周期 P | 每天轮数 | 每天通电时刻 |
|---|---|---|
| 4 小时 | 6 | 00:00、04:00、08:00、12:00、16:00、20:00 |
| 4 小时 48 分 | 5 | 00:00、04:48、09:36、14:24、19:12 |
| 6 小时 | 4 | 00:00、06:00、12:00、18:00 |
| 8 小时 | 3 | 00:00、08:00、16:00 |

例：实测 d = 2 小时 30 分，c = 2 小时 40 分 → Wd = 2 小时 20 分，Wd + c = 5 小时。
选 4 小时 48 分那档（只差 12 分钟）→ Wc = 2 小时 28 分，每天 5 轮。
想保守一点就选 6 小时那档 → Wc = 3 小时 40 分，每天 4 轮，每轮在 100% 多停一个小时。

## 5. Alexa 例行程序

Alexa App 没有简体中文界面，下面按英文界面写（不同版本按钮名字可能略有出入）。

先做一件事：**More → Settings → Hunches**，把自动操作关掉（或把这个插座排除），避免 Alexa 自作主张关插座。

每个通电时刻建一条例行程序（选 4 小时 48 分那档就是 5 条）：

1. **More → Routines → +**
2. 名字：`iPad charge 1`（第二条叫 2，以此类推）
3. **When**（触发）→ **Schedule** → **At Time** → 时间填表里的第一个时刻 → Repeat 选 **Every Day**
4. **Alexa Will**（动作）依次添加 6 个：
   1. **Smart Home** → 选这个插座 → **Power: On**
   2. **Wait** → 5 分钟
   3. **Smart Home** → 插座 → **Power: On**（重复一次，防止第一次指令丢失）
   4. **Wait** → `Wc − 5 分钟`（单个 Wait 最长 4 小时，不够就再加一个 Wait）
   5. **Smart Home** → 插座 → **Power: Off**
   6. **Wait** → 5 分钟，再加一个 **Power: Off**（同样是重复一次）
5. **Save**
6. 其余几条：如果例行程序右上角菜单里有 **Copy Actions to New Routine** 就用它复制，只改名字和时间；没有就照样再建

注意：修改一条正在「等待」中的例行程序会取消它后面的动作。改完后去设备页看一眼插座状态，必要时手动开 / 关一次。

## 7. 日常确认和微调

隔几天看一眼就够：

- **设置 → 电池**：电量曲线应是规则的锯齿
- **网页的运行记录**：每段时长应接近 Wd，结束原因是「进入后台」
- 顺手**点一下网页任意位置**：Safari 会清掉 7 天没人交互过的网站的本地存储，点一下可以保住运行记录。即使被清，循环也不受影响（自动网址不依赖存储），只是历史记录没了

需要调整的信号：

| 现象 | 说明 | 怎么调 |
|---|---|---|
| 每段时长明显短于 Wd，曲线低点长时间平在 10% | 放电比预期快（电池容量在下降，这正是目的），10% 兜底在起作用 | 把所有例行程序的长 Wait **加长**同样的分钟数，相当于缩短放电窗口。空等超过半小时就该调 |
| 曲线高点长时间平在 100% | 充电窗口有富余 | 可以换更短的周期档，重新算 Wc |
| 高点一轮比一轮低 | 充电窗口不够 | 换更长的周期档 |

电池健康每掉几个百分点，d 和 c 都会变短，大约每月重看一次。

## 8. 故障排查

**插座没按时通电 / 断电**
- Alexa App → Devices → 插座：显示 unresponsive 说明掉线。它只连 2.4GHz Wi‑Fi，检查路由器；拔下插座重插一次
- More → Activity 可以看到例行程序有没有执行
- 确认例行程序是 Enabled；确认 Hunches 自动操作已关
- 如果整体偏了整数个小时：检查 Alexa 账户 / 设备的时区设置

**插座通电了但 iPad 没在充**
- 换线、换充电头试；检查接口
- 机身太烫时系统会暂停充电，凉下来自动继续。方案是按时间断电，不会卡死，只是那一轮充得少一点

**断电后网页没开始跑**
- 快捷指令 → 自动化 B：是否「立即运行」；「如果」条件是否「大于 15」；网址是否带 `?auto=1`
- 当时电量是否确实低于 15%（那是设计行为：这一轮跳过，等下一次充电）
- 网页显示「未启用」：说明打开的是普通网址，检查自动化里的网址
- 屏幕上有系统弹窗挡着（更新提示、Apple 账户验证）：处理掉，并确认自动更新已关

**网页显示「上下文丢失，恢复中」**
- 页面会在 5 秒内自己重建并降档运行，多次失败会自动整页重载，一般不用管
- 如果频繁出现：重启一次 iPad

**Safari 标签页越来越多**
- 检查 设置 → App → Safari → 关闭标签页 是否为「一天后」

**iPad 没电关机了**
1. 不用急：下一次插座通电时它会自己充电并开机（也可以在 Alexa App 里手动开插座）
2. 开机后需要**手动解锁一次**（重启后的首次解锁无法自动化）。之后等下一次断电，或手动打开自动网址
3. 找原因：对比网页最后一段记录的结束时间和 Alexa 的 Activity。多数是某次通电没发生（插座掉线、断网），或 10% / 5% 两条自动化被改动过
4. 偶发一次不用改方案；反复出现就把 C 的阈值提到 15%、D 提到 8%，并把放电窗口再缩短 10 分钟

## 9. 查看电池健康度和循环次数

- **较新的机型**（iPad Pro M4 及以后、iPad Air M2 及以后、iPad mini A17 Pro、iPad A16 等）：设置 → 电池 → 电池健康，直接显示最大容量和循环次数
- **老机型**（设置里没有这一项）：
  - Mac 上装 **coconutBattery**（免费），iPad 用线连上 Mac，在 iOS Device 标签里看 Cycle Count、Full Charge Capacity 和 Design Capacity（两者相除就是健康度）。这个最准，建议每周记一次
  - 或者在 iPad 上：设置 → 隐私与安全性 → 分析与改进 → 分析数据 → 打开最新的 `Analytics-日期….ips.ca.synced` → 搜索 `MaximumCapacityPercent` 和 `CycleCount`（需要先开「共享 iPad 分析」，开启后第二天才有文件）
- 系统显示的健康度是平滑过的估算，会滞后于实际容量，不会每天都变。Apple 以自己的诊断结果为准，低于 80% 才算需要更换

## 10. 粗略估算

- **API 请求：0 次**。没有任何额度问题
- 每天轮数：多数 iPad 满载放电 2–3.5 小时，充电 2–3 小时 → 每天 **4–5 轮**
- 每轮约 0.85–0.9 个完整循环 → 每月约 **105–135 个循环**
- Apple 的设计指标是 iPad 电池 1000 个完整循环后保持 80% 容量。按这个算每月掉 2–3 个百分点；每轮深放、充满、机身偏热会更快一些，但快多少没有可靠数据
- 所以：**这是以月计的事**。如果现在健康度已经在 85% 上下，大约 1–3 个月；如果接近 100%，可能要半年左右。以上是估算，实际以每周记录的数字为准

## 11. 安全

- 不要用加热、包裹、遮挡散热等方式加速
- 插座只在室内、0–35°C 环境使用
- 发现屏幕翘起、机身鼓起或变形、异味、异常发烫：立即在 Alexa App 里关掉全部例行程序和插座，停止使用，送修时说明情况
